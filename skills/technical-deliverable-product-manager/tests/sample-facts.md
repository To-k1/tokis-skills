# 合成测试资料：事实依据（不是真实项目）

本文件仅用于检验 Agent。文内所有项目数据均为虚构，并与 sample-A、sample-B 的设定一致。

- 项目目标：做一个能利用内部维修资料辅助问答、返回可点开来源的演示原型。
- 已实现：前端提问和查看回答；资料导入；向量检索；后端引用资料片段调用当前接入的模型；打开资料来源的交互。
- 当前模型：DeepSeek；工程代码有统一模型适配接口，但仅实现并测试了 DeepSeek 接入。其他模型替换属于架构预留能力，不是已验证的运行结果。
- 内部演示资料：120条设备维修知识记录。
- 内部离线验证：36项问答测试，其中31项回答带可打开来源。未提供关于答案准确率、生产效率提升或竞品领先的证据。
- 项目阶段：开发环境演示和离线验证；尚无正式现场部署记录。
- 展示受众：有行业经验但不熟悉大模型技术细节的评委；希望理解项目实际实现的能力及其依据。
