# 维修资料问答：让回答能够找到依据

设备维护人员查找资料时，往往需要在不同的维修记录中反复搜索。这个原型尝试将资料检索与自然语言问答接在一起：使用者输入一个维修问题，系统先从已有记录中寻找相关片段，再由大模型组织回答，并给出可打开的资料来源。

## 目前能做什么

在开发环境的演示中，使用者可以输入问题、阅读回答并打开对应的引用记录。团队整理了120条设备维修知识记录用于演示，进行了36项离线问答测试，其中31项回答附带可打开的来源引用。这个结果说明了原型在该测试条件下的来源追溯表现；它尚不能直接代表生产现场的效果。

## 技术是怎样参与的

系统当前以 DeepSeek 完成问答推理，通过模型适配接口与业务层连接；后端用向量检索找到相关记录，再将问题和检索结果送入模型。架构预留了兼容模型接入位置，但现阶段尚无其他模型的完成适配和测试记录。

## 接下来需要验证什么

若要面向真实现场推广，还需根据实际业务数据验证问答质量、资料覆盖范围与运行稳定性。
