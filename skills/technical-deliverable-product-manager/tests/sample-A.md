# 基于 DeepSeek 的智能技术集成系统

## 技术架构

本系统采用 DeepSeek 作为当前问答推理模型，通过 Web 页面向用户提供交互。系统架构包括前端交互层、模型调用层、知识处理层和资料管理层。各模块通过接口连接，数据按预设流程流转。

在模型调用层，当前实现了 DeepSeek 接入。系统定义了模型适配接口，为未来接入其他兼容模型提供了扩展位置。

## 技术组件

系统使用向量检索定位相关资料片段，再将片段与用户问题一并交给模型生成回答。后端负责处理检索请求、调用模型并返回结果；前端负责展示问答内容。系统另设管理员导入资料的入口。

## 系统功能

当前演示支持输入问题、阅读回答、打开回答引用的资料来源。开发团队整理了120条设备维修知识记录用于内部演示，并进行了36项离线问答测试，其中31项回答带有可打开的来源引用。这些数据反映的是内部测试条件下的结果。

## 应用前景

未来可结合实际业务环境扩大资料范围，评估稳定性并进一步完善现场部署方案。
